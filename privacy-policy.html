プライバシーポリシー（日本語）

本ポリシーは、Yuto Nakanishi（以下「開発者」）が提供する iOS / iPadOS / macOS 向けアプリ「StudyMana」（以下「本アプリ」）の取り扱うユーザー情報について定めるものです。

1. 収集・保存するデータ

本アプリは学習ポモドーロタイマーとして、以下のデータをユーザー自身が登録した内容として保存します。

  • 科目情報（名前、色、アイコン、試験日、目標学習時間）
  • メモ（本文、紐付けられた科目・セッション）
  • 学習セッション履歴（開始時刻、終了時刻、学習時間、フェーズ種別）
  • アプリ設定（タイマー時間、自動開始、サウンド、触覚フィードバック、テーマ等）

本アプリは氏名・住所・電話番号・位置情報・写真・連絡先などの個人識別情報を収集しません。

2. データの保存場所

保存先お使いの iOS / iPadOS / macOS デバイス（SwiftData / Core Data コンテナ）
同期iCloud（CloudKit: iCloud.com.yutonakanishi.StudyMana）
※ご自身の Apple ID 配下のデバイス間で同期され、開発者は閲覧できません
第三者サーバ本アプリ運営者は一切のサーバを運営しておらず、保存データは外部に送信されません

3. iCloud 同期について

本アプリはユーザーの利便性向上のため、上記 1 のデータを Apple の iCloud（CloudKit）を介して、同じ Apple ID で利用している他のデバイスと同期します。iCloud 同期は Apple が提供する仕組みであり、開発者がユーザーのデータを閲覧・収集することは一切できません。iCloud のプライバシーポリシーは Apple のプライバシーに関するポリシー をご確認ください。

4. 通知

本アプリは、ポモドーロタイマーの終了通知のためにローカル通知（UNUserNotificationCenter）を利用します。

  • すべての通知はデバイス内で完結し、外部サーバとの通信は行いません。
  • リモートプッシュ通知は利用しません。
  • 通知の許可は、デバイスの「設定」→ StudyMana → 通知 から変更可能です。

5. Live Activity（iOS のみ）

iOS 16.1 以降のデバイスでは、ロック画面および Dynamic Island 上に進行中のタイマーを表示するため、Live Activity 機能を利用します。表示内容はすべてデバイス内で生成され、開発者のサーバから push 更新を行うことはありません。

6. ショートカット App との連携（集中モード機能）

ユーザーが「集中モード連動」機能を有効にした場合、本アプリは Apple の「ショートカット」App をユーザーが事前に設定したショートカット名で実行します。実行は URL スキーム経由で行われ、ショートカットの実行内容は完全にユーザー側の設定に依存します。開発者はショートカットの内容や実行結果を取得しません。

7. 第三者 SDK・アナリティクス・広告

本アプリは次のいずれも使用しません。

  • アクセス解析／利用状況分析（Firebase Analytics, Google Analytics 等）
  • クラッシュレポート SDK（Crashlytics, Sentry 等）
  • 広告配信・トラッキング SDK
  • その他の第三者 SDK（Swift Package Manager 依存なし）

8. データの保持と削除

本アプリのデータは、ユーザーがアプリ内で削除するか、本アプリをデバイスから削除するまで保持されます。アプリ内「設定」→「詳細」→「すべてのデータを削除」で、登録された科目・メモ・セッション履歴をすべて削除できます。iCloud 同期を有効化していた場合、iCloud 上のデータも上記の削除操作により同期的に削除されます。

9. 子供のプライバシー

本アプリは特に年齢制限なくご利用いただけますが、お子様が利用される場合は保護者の方の監督下でのご利用を推奨します。本アプリは 13 歳未満の方から個人情報を意図的に収集することはありません。

10. セキュリティ

  • 本アプリはデータをデバイス内にのみ保存し、開発者のサーバとは通信しないため、開発者によるデータ漏洩リスクはありません。
  • iCloud 同期データは Apple のセキュリティ基準に従って暗号化されます。詳細は Apple のプライバシーに関するポリシー をご確認ください。

11. ポリシーの変更

本ポリシーは必要に応じて改定される場合があります。重要な変更がある場合は、本アプリのアップデート情報または本ページにて告知します。最新版は常に本ページで確認できます。
